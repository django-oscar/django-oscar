.. _new_in_4.2:

What's new in Oscar 4.2
~~~~~~~~~~~~~~~~~~~~~~~~~~

- Bulk actions in the catalogue dashboard — Reworked bulk actions with an intermediate confirmation step, added bulk updating of public visibility for products and categories, and an option to select objects across all pages. ([#4570](https://github.com/django-oscar/django-oscar/pull/4570), [#4537](https://github.com/django-oscar/django-oscar/pull/4537), [#4535](https://github.com/django-oscar/django-oscar/pull/4535)) — by @mr-sphere, @samar-hassan
- Guest checkout for customers with an existing account — Allow customers who already have an account to check out as a guest. ([#4581](https://github.com/django-oscar/django-oscar/pull/4581)) — by @samar-hassan
- Custom granular permission checks for dashboards. ([#4507](https://github.com/django-oscar/django-oscar/pull/4507)) — by @mfarhan943
- Added a category search form to the dashboard. ([#4536](https://github.com/django-oscar/django-oscar/pull/4536)) — by @samar-hassan
- Made email search more flexible. ([#4558](https://github.com/django-oscar/django-oscar/pull/4558)) — by @samar-hassan
- Added more heading options to TinyMCE. ([#4595](https://github.com/django-oscar/django-oscar/pull/4595)) — by @mr-sphere
